## 📌 Overview  
The **Forgery Image Detection App** is an AI-based application designed to identify manipulated or forged images. It analyzes uploaded images and generates a clear textual report explaining whether the image is authentic or tampered.

## 🎯 Objective  
To detect image forgery using AI techniques and provide a clear, automated explanation.

---

## ⚙️ Features  
- Upload images  
- Detect forgery  
- Generate report  
- Simple UI  

---

## 🛠️ Tech Stack  
- Python  
- GPT-2  
- Hugging Face  
- OpenCV  
- Streamlit  

---

## 🚀 Run  

git clone https://github.com/Devanshi2206/forgery-detection-app.git  
cd forgery-detection-app  
pip install -r requirements.txt  
streamlit run app.py
